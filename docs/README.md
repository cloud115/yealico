# 文档总览

本仓库文档已按 PRD 版本归档，统一采用 `docs/<version>/<category>/...` 结构。

## 平台范围

- 运行目标：Android App
- 开发/调试目标：Web

## 目录结构

- `docs/1.0.0/PRD/`
- `docs/1.0.0/architecture/`
- `docs/1.0.0/progress/`
- `docs/1.0.0/qa/`
- `docs/1.0.0/release/`
- `docs/1.0.1/PRD/`
- `docs/1.0.1/architecture/`
- `docs/1.0.1/progress/`
- `docs/1.0.1/qa/`
- `docs/1.0.1/release/`

## 快速入口

- `1.0.0` 索引：`docs/1.0.0/README.md`
- `1.0.1` 索引：`docs/1.0.1/README.md`
- 规则样例目录：`docs/rules/samples/`

## 版本规则

- PRD 版本是发布版本来源。
- `pubspec.yaml` 的 `build-name` 必须与目标 PRD 版本一致。
- `build-number` 继续按内部构建号递增。
