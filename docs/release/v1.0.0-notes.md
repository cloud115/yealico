# Release v1.0.0

This is the PRD `1.0.0` baseline release for the Yealico MVP.

## Highlights

- GitHub Raw rule import flow is available.
- Rule validation and dev/prod error policy are implemented.
- Site list, catalog list, detail list, and content parsing are connected end to end.
- Image reader and video playback entry are available.
- Release process, QA checklist, and delivery artifacts are documented.

## Included Scope

- Planned MVP work from `T01` through `T17`
- Implementation
- Automated verification
- Release process assets

## Build Artifacts

- Android APK: `build/app/outputs/flutter-apk/app-release.apk`
- Web bundle: `build/web/`

## Validation

- Automated tests: `flutter test`
- Manual checklist: `docs/qa/t16-acceptance-checklist.md`
- Delivery report: `docs/release/t17-delivery-report-2026-04-15.md`

## Known Limitations

- JavaScript-dependent sites are not supported by the direct rule runtime.
- WebView/original-page fallback is still out of scope.
- Novel/text reading is out of scope for this baseline.

## Versioning

- PRD version: `1.0.0`
- App release version: `1.0.0`
- Build number: `1`
