# Release v0.1.0

首个 MVP 版本，完成从规则导入到图文/视频内容消费的端到端流程，并提供 Android 与 Web 构建产物。

## Highlights

- 支持通过 GitHub Raw URL 导入规则并完成基础预处理。
- 新增规则校验与结构化问题输出，区分开发/生产错误策略。
- 打通站点列表 -> 目录列表 -> 详情列表 -> 内容页的核心浏览链路。
- 支持图片内容解析与阅读器（翻页、缩放、索引）。
- 支持视频内容解析与基础播放页能力。
- 增加基础缓存与性能优化（HTML 请求缓存、TTL 缓存、阅读预取）。

## Included Scope

- 覆盖 T01-T17 的 MVP 计划任务（实现、测试、发布流程）。

## Build Artifacts

- Android APK: `build/app/outputs/flutter-apk/app-release.apk`（约 49.1 MB）
- Web Bundle: `build/web/`

## Validation

- Automated tests: `flutter test` 全部通过（34/34）
- Manual checklist: `docs/qa/t16-acceptance-checklist.md`
- Delivery report: `docs/release/t17-delivery-report-2026-04-15.md`

## Known Limitations

- 暂不支持依赖浏览器 JS 执行后的动态站点抓取。
- 暂不提供解析失败后的原网页回退（WebView fallback）。
- 小说/纯文本阅读能力不在当前 MVP 范围内。
