# 安卓版站点内容净化阅读器 PRD (MVP)

## 1. 背景与目标
**背景**：安卓平台缺乏类似 iOS 应用 Yealico 的站点聚合与净化阅读工具。用户在安卓手机浏览漫画/图集及视频站点时，深受页面排版混乱、侵入式广告困扰。
**目标**：开发一款安卓 App (MVP)，支持通过网络导入托管在 GitHub 的站点解析规则，实现漫画/图集的沉浸式左右翻页阅读，以及视频的净化播放。

## 2. 用户角色
- **内容消费者**：希望获得无广告、排版整洁的漫画/图集浏览体验的安卓用户。
- **规则维护者**（非 App 内角色）：负责在 GitHub 更新和维护站点解析脚本的人员。

## 3. 核心业务流程（分支文本描述）
1. 用户打开 App
2. 系统检查是否已有规则
   - 情况 A：没有规则
     a. 用户点击“导入规则”
     b. 弹出输入框，用户粘贴 GitHub Raw 链接
     c. App 下载并解析规则
     d. 判断解析结果：
        - 成功 → 进入步骤 3
        - 失败 → Toast 提示“规则解析失败”，流程终止
   - 情况 B：已有规则
     a. 直接进入步骤 3
3. 规则列表更新，展示可用站点
4. 用户点击目标站点
5. 展示内容目录或剧集列表
6. 用户选择内容类型
   - 类型一：漫画/图集
     a. 进入图片解析页
     b. 尝试解析图片地址：
        - 成功 → 进入左右翻页阅读器（无广告）
        - 失败 → Toast 提示“解析失败 请检查规则”，返回列表
   - 类型二：视频
     a. 进入视频解析页
     b. 尝试解析视频地址：
        - 成功 → 调用播放器净化播放
        - 失败 → Toast 提示“解析失败 请检查规则”，返回列表

## 4. 功能详述 (MVP)

### 4.1 规则管理模块
- **导入方式**：仅支持 **粘贴 GitHub 原始链接** 导入。
- **链接格式要求**：用户需在输入框内粘贴指向 `.js` 或 `.json` 规则文件的直链（Raw URL）。
- **导入逻辑**：
    1. 点击“导入规则”按钮，弹出输入框。
    2. 用户粘贴链接后点击确认。
    3. App 发起网络请求下载文件内容。
    4. **成功**：校验文件格式并存入本地数据库，刷新站点列表。
    5. **失败**：返回明确的 `Toast` 提示“规则解析失败”（不区分网络错误或格式错误，统一提示）。

### 4.2 漫画/图集浏览模块
- **入口**：站点列表 -> 选择漫画/图集分类 -> 进入详情目录 -> 选择章节/相册。
- **阅读模式**：**强制左右翻页阅读器**。
- **交互细节**：
    - 点击屏幕左侧向前翻页，点击右侧向后翻页。
    - 支持手势滑动翻页（左滑/右滑）。
    - 顶部栏显示当前页码/总页数，且自动隐藏。
- **解析逻辑**：根据规则提取当前页面的图片直链列表。
- **异常处理**：
    - 若规则匹配不到图片地址，**不降级显示原网页**，直接 `Toast` 提示：“解析失败，请检查规则”。

### 4.3 视频播放模块
- **入口**：站点列表 -> 视频站点 -> 选择剧集。
- **播放逻辑**：解析视频源地址，调用系统原生/自定义播放器全屏播放。
- **净化要求**：拦截播放器加载过程中的网页广告弹窗（由规则脚本负责定位真实视频地址，App 仅负责播放该地址）。
- **异常处理**：解析不出视频地址时，`Toast` 提示：“解析失败，请检查规则”。

### 4.4 功能边界 (明确本期不做)
- **小说阅读**：本期不支持文字小说排版与翻页。
- **内置规则市场**：不提供应用内浏览 GitHub 仓库文件列表的 UI，用户必须自行粘贴直链。
- **降级浏览器模式**：解析失败时，**不允许**自动跳转系统浏览器或 WebView 原网页浏览。

## 5. 验收标准
| 模块 | 验收点 | 预期结果 |
| :--- | :--- | :--- |
| **规则导入** | 粘贴正确的 GitHub Raw 链接 | 提示成功，站点列表显示新站点 |
| **规则导入** | 粘贴错误的链接或无效脚本 | `Toast` 提示“规则解析失败”，站点列表无变化 |
| **漫画阅读** | 进入支持的漫画站点章节 | 全屏显示第一页，点击右侧翻至第二页 |
| **漫画阅读** | 进入失效/规则不匹配的站点 | `Toast` 提示“解析失败，请检查规则”，屏幕不跳转原网页 |
| **视频播放** | 进入支持视频站点播放页 | 全屏播放视频，无网页弹窗广告 |
| **视频播放** | 视频地址解析失败 | `Toast` 提示“解析失败，请检查规则” |
| **边界测试** | 测试小说网站导入 | 即使规则支持，App 内不处理文字排版（由规则自行限制或 App 内屏蔽） |
