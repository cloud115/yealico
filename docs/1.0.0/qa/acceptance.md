# T16 验收清单（MVP）

## 范围

本清单用于验证 MVP 在以下方面的行为：

- 规则导入
- 目录/详情/内容解析流程
- 图片阅读器
- 视频解析与播放入口
- 明确的非范围边界

## 环境

- 目标平台：Android、Web
- 构建模式：
  - dev：显示详细错误
  - prod：显示通用用户错误

## 验收矩阵

### A. 规则导入

1. 导入有效 GitHub Raw 规则
- 步骤：
  - 打开首页
  - 点击 `Import Rule (T04)`
  - 输入有效 raw URL
  - 点击 `Import Rule`
  - 点击 `Add To Site List (T07)`
- 预期：
  - 无校验失败
  - 站点出现在 `Imported Sites`

2. 导入无效规则（缺少必填字段）
- 步骤：
  - 导入已知无效样例
- 预期：
  - 校验失败
  - dev 模式：显示详细问题列表
  - prod 模式：显示通用错误文案

3. 导入非 GitHub Raw URL
- 步骤：
  - 输入非 raw URL
- 预期：
  - 导入被拒绝，并给出明确提示

### B. 目录与详情解析

4. 从导入站点打开目录
- 步骤：
  - 在站点卡片点击 `Open Catalog (T08)`
- 预期：
  - 目录页可加载
  - 列表/空态/错误态行为正确

5. 从目录项打开详情列表
- 步骤：
  - 在目录项点击 `Open Details (T09)`
- 预期：
  - 详情页可加载
  - 列表/空态/错误态行为正确

### C. 图片内容与阅读器

6. 从详情项解析图片 URL（`comic/gallery`）
- 步骤：
  - 在详情项点击 `Parse Images (T10)`
- 预期：
  - 成功展示图片 URL 列表

7. 打开图片阅读器
- 步骤：
  - 点击 `Open Reader (T11)`
  - 点击左右区域并滑动
- 预期：
  - 页码正确更新
  - 左右点击翻页可用
  - 滑动翻页可用

### D. 视频内容与播放入口

8. 从详情项解析视频 URL（视频站点）
- 步骤：
  - 点击 `Parse Video URL (T12)`
- 预期：
  - 成功展示解析后的视频 URL

9. 打开视频播放器
- 步骤：
  - 点击 `Play Video (T13)`
- 预期：
  - 播放器页面可打开
  - 可见基础播放/暂停与拖动控制

### E. 错误策略

10. Dev 模式错误可见性
- 步骤：
  - 触发已知错误（无效导入 URL）
- 预期：
  - 显示详细错误信息

11. Prod 模式错误可见性
- 步骤：
  - 使用 `main_prod.dart` 运行
  - 触发同一错误
- 预期：
  - 显示通用兜底错误文案

### F. 明确非范围验证

12. 小说/文本阅读支持
- 预期：
  - MVP 流程不提供该能力

13. 依赖浏览器 JS 执行的网站
- 预期：
  - 不支持站点会解析失败（无 JS 回退运行时）

14. 解析失败后的 WebView/原网页回退
- 预期：
  - 不启用回退，仅显示错误提示

15. 内置规则市场
- 预期：
  - 不提供该功能

## 通过标准

- 所有范围内必测项（A-D、E）通过。
- 非范围项（F）被确认是有意不实现。
