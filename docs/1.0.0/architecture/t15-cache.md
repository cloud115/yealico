# T15 缓存与基线性能优化

## 目标

在不改变业务行为的前提下，加入基线运行时优化。

## 已实现

- 新增通用 TTL 缓存工具：
  - `lib/core/cache/ttl_cache.dart`
- 在抓取器加入 HTML 请求级短期缓存：
  - 缓存键：URL + headers + charset
  - 默认开启缓存
  - TTL 可配置
- 在抓取器加入超时归一化：
  - 下限 3 秒
  - 上限 30 秒
- 提升阅读器体验性能：
  - 邻近图片预取（上一张/下一张）
  - 图片网络加载阶段显示 loading 指示

## 边界

- 缓存当前仅内存态。
- 本步骤不包含持久化缓存。
- 本步骤不包含激进媒体预加载策略。
