# T10 图片内容解析

## 目标

针对 `comic/gallery` 站点，从选中详情项解析图片 URL 列表。

## 已实现

- 新增 `ImageContentLoader` 抽象与运行时实现。
- 新增 `ImageContentPage`：
  - 异步加载图片 URL
  - 加载/错误/空态/列表态
- 连接详情页动作：
  - 非视频站点：`Parse Images (T10)`
  - 视频站点：标记到 `T12`

## 边界

- 本步骤仅提取并展示图片 URL。
- 不包含阅读器交互（翻页/手势，留到 `T11`）。
- 不包含视频解析与播放（留到 `T12+`）。
