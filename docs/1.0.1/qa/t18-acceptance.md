# T18 验收清单（PRD 1.0.1 Runtime Hardening）

## 范围

本清单覆盖 1.0.1 的关键增强能力：

- 渲染抓取与挑战页检测
- 受保护资源请求头透传
- `decryptScript` 优先解析
- 阅读器并发/节流预取
- 可视化会话验证后目录刷新

## 环境

- Android（主验收目标）
- Web（开发代理验证）

## 验收项

1. 目录页可触发会话验证
- 步骤：进入目录页，点击 `Verify Session`
- 预期：打开验证页；点击 `Done and Refresh` 返回后目录自动重载

2. 站点挑战页检测
- 步骤：访问触发挑战的站点
- 预期：抛出验证中异常并显示用户可理解提示

3. 图片资源请求头透传
- 步骤：解析受 Referer/Cookie 保护的图片内容
- 预期：阅读器内图片可加载，无明显 403 裂图

4. 视频请求头透传
- 步骤：解析视频并进入播放器
- 预期：播放器初始化时带上 runtime 头信息，视频可正常拉流

5. `decryptScript` 生效
- 步骤：规则配置 `decryptScript` 且页面 selector 无法直接提取资源
- 预期：仍可从解密结果得到资源列表/视频链接

6. `decryptScript` 异常处理
- 步骤：提供非法解密返回结果
- 预期：抛出脚本执行异常并走错误策略

7. 阅读器预取窗口
- 步骤：连续翻页
- 预期：预取范围为当前页前后 2 页

8. 阅读器预取并发/节流
- 步骤：快速连续翻页
- 预期：预取并发不超过 3，且具备节流，UI 保持可用

## 通过标准

- 上述 8 项全部满足
- 无因 1.0.1 改造引入的 P0/P1 回归
