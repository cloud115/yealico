# 发布说明 v1.0.1

## 版本信息

- PRD 版本：`1.0.1`
- App 版本：`1.0.1+2`

## 亮点

- Android 运行时升级为渲染抓取编排，增强反爬站点兼容性。
- 支持 `decryptScript` 解析结果优先输出内容资源。
- 图片与视频播放链路支持请求头透传（Referer/Cookie/UA）。
- 阅读器加入预取并发与节流策略，提升连续翻页稳定性。
- 新增目录页 `Verify Session` 入口，支持会话验证后刷新目录。

## 质量状态

- 自动化测试：`flutter test` 全量通过。
- 验收清单：`docs/1.0.1/qa/acceptance.md`
- 测试报告：`docs/1.0.1/qa/test-report.md`

## 已知限制

- Web 端在本地调试阶段，部分强反爬站点可按需使用开发代理辅助（仅限调试）。
- 个别站点需要规则层持续调优。
